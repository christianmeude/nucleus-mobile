How to install

  1. Tap Download for Android above on your Android phone.
  2. Open the downloaded .apk file. Android will ask to allow Install unknown apps — tap Allow. This is normal for apps installed outside the Play Store.
  3. If you see “Unknown app — Install anyway?”, tap Install anyway. The file comes from us, so it is safe to install.
  4. Tap Open to launch NUcleus Mobile.

Classroom / orientation install

Scan the QR code on the poster with your phone camera — it opens this page. Then follow the steps above.

Updates

Small fixes download automatically — just close and reopen the app. If we release a big update, this page will say “Please re-download” and you will need to install the new .apk over the old one (no uninstall needed).

Having trouble?

  • “App not installed”: you may have a very old test copy. Uninstall any copy named NUcleus Mobile (Dev) or NUcleus Mobile (Preview) first, then reinstall. The real app is just NUcleus Mobile.
  • “Blocked by Play Protect”: tap More details → Install anyway. This warning appears for all sideloaded apps.
  • Download won’t open: look in Files → Downloads for the .apk, or re-download using Chrome.
  • Still stuck? Contact support at nucleus-support@nu-dasma.edu.ph.
