How to install

  1. On your Android phone, tap Download for Android above.
  2. Open the downloaded file. If Android asks to allow Install unknown apps, tap Allow for the app that downloaded it (usually Chrome or Files). This is normal outside the Play Store.
  3. If you see Unknown app — Install anyway?, that warning appears for every app installed outside the Play Store, including ours. If you came from this official page, tap Install anyway.
  4. Tap Open to launch NUcleus Mobile.

Having trouble?

  • App not installed: you may have an old test copy. Uninstall any copy named NUcleus Mobile (Dev) or NUcleus Mobile (Preview) first, then reinstall. The real app is just NUcleus Mobile.
  • Blocked by Play Protect: tap More details, then Install anyway. If your phone offers no Install-anyway option, update Play Protect / Android and retry.
  • Download won’t open: open Files, then Downloads, and tap the file. If it stalls, re-download using Chrome on Wi-Fi.
  • On iPhone? This release is Android-only.
About updates

Small fixes arrive automatically when you reopen the app. If a big update needs a fresh file, this page will say Please re-download. Install the new file over the old one, no uninstall needed.
