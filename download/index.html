03 — Sideload in minutes

Four taps to installed.

  1. On your Android phone, tap Download for Android above.
  2. Open the downloaded file. If Android asks to allow Install unknown apps, tap Allow for whichever app downloaded the file (usually Chrome, or Files if you moved it there). This is normal outside the Play Store.
  3. If you see Unknown app — Install anyway?, that warning appears for every app installed outside the Play Store, including ours. If you came from this official page, tap Install anyway.
  4. Tap Open to launch NUcleus Mobile.

Hit a wall?

App not installed

You may have an old test copy. Uninstall any copy named NUcleus Mobile (Dev) or NUcleus Mobile (Preview) first, then reinstall. The real app is just NUcleus Mobile.

Blocked by Play Protect

Tap More details, then Install anyway. If your phone offers no Install-anyway option, update Play Protect / Android and retry.

Download won’t open

Open Files, then Downloads, and tap the file. If it stalls, re-download using Chrome on Wi-Fi.

On iPhone?

This release is Android-only.
